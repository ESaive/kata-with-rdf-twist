Prompt 3 
I wrote a small RDF-backed storage layer for the Gilded Rose inventory using rdflib. Each item is added as a resource with predicates for name, sellIn, and quality. Updates modify those values directly in the graph.
Here is a simplified version of the implementation:
from rdflib import Graph, Namespace, Literal

class RDFInventoryStore:
   def __init__(self):
       self.graph = Graph()
       self.ns = Namespace("http://example.com/inventory/")

   def add_item(self, name, sell_in, quality):
       item = self.ns[name]
       self.graph.add((item, self.ns.name, Literal(name)))
       self.graph.add((item, self.ns.sellIn, Literal(sell_in)))
       self.graph.add((item, self.ns.quality, Literal(quality)))

   def update_item(self, name, sell_in, quality):
       item = self.ns[name]
       self.graph.set((item, self.ns.sellIn, Literal(sell_in)))
       self.graph.set((item, self.ns.quality, Literal(quality)))
Can you review this code and point out if there are any issues with how the RDF graph is being updated or structured?
Response (Summary)
The implementation is reasonable for a small RDF-backed storage layer.
Using Graph.set() works well because it replaces the existing value for a predicate instead of creating duplicate triples.
One improvement suggested was defining item types using rdf:type rather than depending only on item names. This makes the data structure clearer and easier to extend.

Prompt 4 
How do you serialize an rdflib.Graph to a Turtle file from Python after updates are complete?
Response (Summary)
The graph can be exported to a .ttl file using the serialize() method from RDFLib.
Example:
graph.serialize(destination="inventory.ttl", format="turtle")
This writes the current state of the RDF graph to a Turtle file.

What is a clean way to run a small multi-day simulation in Python where item states are printed after each day?
Response (Summary)
A simple loop can be used to simulate multiple days.
For each day:
Print the day number


Print the current state of items


Run the update logic


Example structure:
for day in range(days):
   print(f"-------- day {day} --------")

   for item in items:
       print(item)

   update_quality(items)
This makes it easy to observe how item values change over time.

Prompt 7 
While running the tests I got the following warning and errors:
warnings summary
..\ .venv\Lib\site-packages\_pytest\config\__init__.py:1428
PytestConfigWarning: Unknown config option: python_paths

ERROR test_rdf.py
ERROR tests\test_gilded_rose.py
ERROR tests\test_gilded_rose_approvals.py
Interrupted: 3 errors during collection
What does this warning mean and how can it be fixed?

Response (Summary)
The warning appears because pytest does not recognize the configuration option python_paths.
This usually happens when the option name is written incorrectly in the pytest.ini file.
The incorrect configuration:
[pytest]
python_paths = .
The correct configuration:
[pytest]
pythonpath = .
The correct option is pythonpath (singular).
 This setting adds the current project directory to Python’s module search path so that test files can import project modules correctly.
After correcting the configuration and running the tests again, the warning is removed and pytest can properly collect the test files.
